# Confirm the request

```xml
<entry>
  Confirm new requests or changes to target, scope or resource authorization.
  Otherwise resume at the recorded stage.
</entry>

<action>
  Summarize hardware, model, tested framework, task (inference, SFT or RL) and
  scope in the user's language. For a general check, propose a small end-to-end
  case for that task. Confirm once, including local or remote resources,
  reference access and limits for setup, execution and follow-up.
</action>

<output>
  Record the confirmed scope, resource authorization, pending items, pinned
  versions and any acceptance criteria. Resolve discoverable versions, exact
  device IDs and launch commands during environment preparation.
</output>

<next>
  Retrieve community records after confirmation. A missing resource grant
  blocks only its dependent work; continue independent authorized preparation.
</next>
```

# Gemma 4 12B: H100 / Ascend fixed-history text pilot

The H100 and Ascend peers completed three fresh sequential TP1 captures each, followed by a full-row evidence check, 15 pairwise comparisons and an independent numerical check. This release covers one fixed text input. Numerical thresholds and acceptance are null. The original 49-task plan, including its 28 core tasks, remains incomplete; the [coverage ledger](coverage.json) records every remaining cell.

The base checkpoint is `google/gemma-4-12B`, revision `1a2c7729392586f5ecddae8807ee2ef741eabb9a`. Its eight selected official files were checked on both hosts. The weight SHA256 is `fe054ae05ff7f44318fd8ae90d58992531455c7ed31356704088f0f2d8c8009a`; the frozen input SHA256 is `643d29f23d00f97665c5c72d73c63bc20525950b2ca5c50b435140b6066214f0`. Both sides used `Gemma4UnifiedForConditionalGeneration`, BF16 parameters, eager attention, seed 0, batch 1, 128 prompt tokens including BOS and 32 predetermined continuation targets. One prefill plus 31 cached single-token forwards produced 32 continuation prediction distributions per capture. Text execution leaves the checkpoint's non-text branches outside this release.

The GPU was an NVIDIA H100 80GB HBM3, using Torch `2.9.0+cu128`, CUDA `12.8`, Transformers `5.10.1` and NumPy `1.26.4`. A separate original native query recorded NVIDIA driver `580.95.05` and matched the captured device UUID; this supplements the unchanged collector receipts. The NPU runtime reported `Ascend910_9382`, Torch `2.9.0+cpu`, TorchNPU `2.9.0.post2`, Transformers `5.10.1`, CANN `9.1.0` and driver metadata `25.5.2`. The NPU instance exposed eight logical devices; each capture used one. No eight-device parallel inference was measured.

Both policies configured highest FP32 matmul precision, disabled matmul TF32/HF32, enabled convolution TF32/HF32, disabled deterministic algorithms and set `PYTHONHASHSEED=0`. GPU cuDNN benchmarking was disabled; NPU JIT compilation was disabled. Exact configured/read-back policies and intentional backend differences are retained in [selected metrics](selected-metrics.json). These are BF16 model executions with derived FP64 log probabilities. Original native logits were not retained.

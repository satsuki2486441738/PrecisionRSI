# Gemma-4 precision source supplement

This supplement adds six CPU reference sources to source release v1. They cover
the dual observer admission and independent check, Reserved48 mixed-profile CPU
reduction, and the P128 paired driver and retained metadata staging. The earlier
release provides shared dependencies and public input provenance.

The indexed ZIP preserves repository-relative names. The embedded export index
and its sibling index record separate SHA-256 digests for each original and
delivered source. The sibling index also records each transformation. Actual
platform identifiers and deployment path literals were replaced. The delivered
command-line entry points refuse before importing dependencies, and the observer
endpoint activation is unset. Original dependency pins identify observed source
bytes.

The archive contains Python reference sources and their export index. Supporting
evidence, model and tensor data, platform configuration, runtime environment and
operation scripts are handled separately. Running a comparison requires a
separately reviewed execution context and its corresponding original evidence.

# Gemma 4 12B: H100 / Ascend text partitions and repeatability

H100 and Ascend completed the same five modes through one loaded model per backend: three cache-off full forwards, token decode, and unequal-chunk prefill followed by token decode. The primary results compare GPU and NPU under matched modes. The independent CPU admission checked all retained raw BF16 predictions, reconstructed 1,590 target scores and 470 selected full-vocabulary rows, and produced 23 score/distribution comparisons plus four final K/V comparisons. Acceptance and numerical thresholds remain null. This is a one-input text milestone; the [49-task coverage ledger](coverage.json), including 28 core tasks, remains incomplete.

The base checkpoint is `google/gemma-4-12B`, revision `1a2c7729392586f5ecddae8807ee2ef741eabb9a`, loaded through `Gemma4UnifiedForConditionalGeneration`. Weight SHA256 is `fe054ae05ff7f44318fd8ae90d58992531455c7ed31356704088f0f2d8c8009a`; input SHA256 is `643d29f23d00f97665c5c72d73c63bc20525950b2ca5c50b435140b6066214f0`. Both sides used BF16 parameters, eager attention, batch 1 and the same 128 prompt tokens including BOS plus 32 predetermined continuation tokens. Python, NumPy, Torch CPU and device generator state observations were reset before each mode with seed 0. Per-process model object/storage observations, parameter versions, configuration and small-buffer hashes were checked before and after each mode. These observations do not attest identical random streams across hardware or reset allocator/kernel warmup state.

The GPU was an NVIDIA H100 80GB HBM3 with driver `580.95.05`, Torch `2.9.0+cu128`, CUDA `12.8`, Transformers `5.10.1` and NumPy `1.26.4`. The NPU reported `Ascend910_9382`, Torch `2.9.0+cpu`, TorchNPU `2.9.0.post2`, CANN `9.1.0`, driver metadata `25.5.2` and the same Transformers/NumPy versions. The NPU instance exposed eight logical devices; the measured model used one. No eight-device parallel result is claimed. The H100 physical identifier differed from preceding stages; measurements across stages do not isolate a single changed setting.

Each full mode supplied all 160 inputs in one call with `use_cache=False`. Token mode used one 128-token prefill and 32 single-token calls. Chunk mode used 63-token and 65-token prefills followed by 32 single-token calls. Both cached modes consumed all 160 supplied inputs, retained the final native cache and used unchanged fixed histories. The last supplied input produces an unscored prediction row and final state; no unknown target 160 is invented. Each backend made 70 native forwards in total. Each of its five raw outputs has shape `[1,160,262144]`, retained losslessly in BF16 safetensors. All 1,600 raw prediction rows across both backends were checked for finiteness. Prediction rows 0–158 supply all 159 valid targets per mode. Sixteen prompt positions and 32 continuation prediction positions deduplicate to 47 distribution rows because position 127 belongs to both sets. Derived log probabilities and offline reductions use FP64.

Across full-forward GPU/NPU pairs, H100 NLL was **3.2764746913920972 nat/token** and Ascend NLL was **3.2694529714979046 nat/token**. Absolute NLL difference was **0.007021719894192646 nat/token**. Target logprob MAE was **0.033320404862961756 nat**, linear P99 **0.1683911049445629 nat**, and maximum **0.18670247219334346 nat**, at target position 57. All nine combinations of the three GPU and three NPU full repeats produced these same metrics. They remain repeated observations of one input.

For the full-forward cross-backend comparison, sampled Top-1 agreement was **47/47**, mean top-100 overlap **0.981063829787234**, mean probability RMSE **0.0012939709694624343** and maximum probability RMSE **0.00470915635838022**. All three distribution maxima occurred at prediction position 134. Probability errors cover the union of each side's top-100 tokens; JS uses that union plus an exact complement category and is a coarsened divergence.

Matched GPU/NPU token decoding had target MAE **0.03843523907491317 nat**, P99 **0.166071650970308 nat**, maximum **0.21872016171609765 nat**, and sampled Top-1 agreement **46/47**. Lower disagreement between peer devices does not establish lower error against a mathematical reference or better task quality.

All six within-backend full-repeat pairs had zero target-score differences and zero reported sampled-distribution probability errors and JS, with Top-1 agreement 47/47. Fresh-process repeatability and repeated cached-mode execution were not measured in this stage. Each cached path ran once per backend. Safetensors file hashes include mode metadata, so zero compared values do not imply identical whole-file hashes.
